# zh-TW 翻譯名詞字典表

此文件記錄 zh-TW 語系中經過特別確認的名詞翻譯規則。

## 保留原文的名詞

| 英文原文                | zh-TW 翻譯                          | 說明                                                                                  |
| ----------------------- | ----------------------------------- | ------------------------------------------------------------------------------------- |
| Git Worktree            | Git Worktree                        | 保留原文，符合繁體業內習慣                                                            |
| Roadmap                 | Roadmap                             | 保留原文                                                                              |
| AI Review               | 選單/Lane：AI Review；其他：AI 審查 | 僅選單和 Kanban lane 保留原文，描述性文字翻譯為「AI 審查」                            |
| Blocking Issue          | Blocking Issue                      | 保留原文，「阻擋問題」較難理解                                                        |
| Token                   | Token                               | 保留原文，不翻譯為「權杖」                                                            |
| Embedding               | Embedding                           | 保留原文，不翻譯為「嵌入」（注意：「嵌入式資料庫」的「嵌入式」是 embedded，維持中文） |
| Blocker                 | Blocker                             | 嚴重程度等級，保留原文                                                                |
| Idea / Ideas / Ideation | 選單：Ideas；描述性文字：構想       | 選單項目保留原文 Ideas，描述性句子中翻譯為「構想」                                    |
| Kanban                  | 選單：Kanban；其他：看板            | 僅選單項目保留原文，描述性文字翻譯為「看板」                                          |
| Insights                | Insights                            | 保留原文                                                                              |
| Changelog               | 選單：Changelog；其他：變更日誌     | 僅選單項目保留原文                                                                    |
| Context                 | 選單：Context                       | 選單項目保留原文                                                                      |
| Agent Terminals         | 選單：Agent Terminals               | 選單項目保留原文                                                                      |
| Kanban Lane 名稱        | 保留英文原文                        | Backlog, Queue, In Progress, Planning, AI Review, Done, PR Created, Error 等          |

| pull request            | Pull Request / PR                   | 保留原文                                                                              |
| merge request           | Merge Request / MR                  | 保留原文                                                                              |

## 格式規則

- **中英文混用加空白**：中文與英文/數字之間必須加空白（例如：「建立 Git Worktree」）
- **全形標點後不加空白**：全形標點符號（，、：（）「」等）後接英文時不加空白
- **英文名詞首字大寫**：保留原文的名詞首字母大寫（例如：Idea、Roadmap）
- **單複數對應**：保留原文的英文名詞需對應英文原文的單複數形式
